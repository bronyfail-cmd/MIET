# Тестовые сценарии и отчёт о качестве

## Автотесты (43, pytest)
- tests/test_methods.py — загрузчик (битые JSON), контракт вопросов, инварианты
  подсчёта по всем методикам, ключи choice, отклонение некорректных баллов,
  пропуски, ipsative-подсчёт.
- tests/test_engine.py — порядок блоков, границы навигации, валидация ответов,
  пропуски и группировка, изоляция неизвестных и падающих блоков.
- tests/test_collector_validator.py — формат результата, полнота портрета,
  missing/invalid, выбор лучшей реализации пары, проверки валидатора
  (дубликаты, пустые тексты, битые ключи, субшкалы, уровни).
- tests/test_web.py — регистрация и валидация ФИО/группы, полный проход опроса,
  возврат назад и продолжение черновика, отказ пустого ответа, чужие попытки,
  фильтры и экспорт админки, CSRF, устойчивость фильтров к SQL-инъекциям.

## Ручной чек-лист приёмки
1. Варианты ответа отображаются текстом с нумерацией («1) верно»), без баллов ключа.
2. Шкалы показывают позиции 1..N, не цифры ключа.
3. Экран паузы не пропускает вопросы при повторном нажатии.
4. Админка: баллы без «.0», фильтры и счётчик строк работают.
5. «Портрет» открывается по ссылке из админки и после завершения опроса.
6. Регистрация отклоняет ФИО «,e,e» и группу с запятыми.
7. Блок «Стили коммуникации»: пары утверждений, выбор одного варианта из пары.
