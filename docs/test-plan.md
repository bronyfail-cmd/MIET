# Тест-план и приёмка

Запуск: `pytest` (43 автотеста). Ручная проверка — по чек-листу ниже.

## Автоматизированные сценарии
| Область | Что проверяется | Файл |
|---|---|---|
| Методики | максимум/минимум с обратными пунктами, субшкалы, ключи choice, ответы вне шкалы, пропуски (порог 20%), битый JSON | `tests/test_methods.py` |
| Движок | порядок блоков, границы навигации, валидация ответа, пропуски, отказ блока (нет/исключение/пусто) | `tests/test_engine.py` |
| Сборщик | формат результата, отсутствие потерь и дублей, missing/invalid, лучший из пары, сбой блока | `tests/test_collector_validator.py` |
| Валидатор | норма, отсутствующая методика, битые модули (дубликаты, пустой текст, неверный ключ, субшкала, уровни) | `tests/test_collector_validator.py` |
| Сайт | доступ без входа, регистрация/дубликат/пароль, полное прохождение, пропуск/назад/возобновление, неверный ответ, чужие результаты (403), фильтры преподавателя, SQL-инъекция, CSRF, open redirect, экспорт | `tests/test_web.py` |

## Ручной чек-лист
1. Регистрация → вход → «Пройти опрос».
2. Ответить на все вопросы → «Завершить» → открывается портрет, есть все методики.
3. Начать новую попытку, закрыть вкладку на середине → «Продолжить» возвращает на тот же вопрос.
4. Пропустить 2+ вопроса в короткой методике → в портрете метка «неполный».
5. «Назад» меняет ответ и сохраняет его.
6. Скачать JSON и CSV (CSV открывается в Excel с кириллицей).
7. Под преподавателем: фильтры по группе/методике/уровню/датам, экспорт, `/admin/validate`.
8. Испортить JSON методики → `flask validate` возвращает ошибку и ненулевой код.

## Критерии приёмки
- Все автотесты зелёные; `flask validate` без ошибок (предупреждения о демо допустимы до получения материалов).
- В портрете присутствуют все подключённые методики, нет дублей.
- Сбой одного блока не останавливает опрос и сборку.
- Студент не видит чужих результатов.

## Известные ограничения
- Методики — демо-заглушки до получения вопросов и ключей.
- Нет восстановления пароля и подтверждения e-mail.
- SQLite подходит для нагрузки уровня группы/потока; для большего — PostgreSQL.
