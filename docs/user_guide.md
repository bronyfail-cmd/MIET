# Руководство пользователя

## Студент
1. Открой сайт, нажми «Регистрация»: ФИО (минимум два слова буквами),
   группа (начинается с буквы/цифры, без запятых), e-mail, пароль от 6 символов.
2. После входа — страница опроса: инструкция, затем вопросы блоками по методикам.
   Внизу — прогресс («Вопрос N из 491», «отвечено M»).
3. Кнопки: «Далее» (ответ обязателен), «Назад», на последнем вопросе «Завершить».
   Между смысловыми блоками — экран паузы «Продолжить тестирование».
4. Черновик сохраняется: повторный «Начать тестирование» возвращает на то же место.
5. После завершения — «Портрет личности»: баллы, уровни и выводы по каждой
   методике; кнопки JSON и CSV — экспорт своей попытки.

## Преподаватель
1. Учётную запись создаёт администратор сервера:
   flask --app wsgi create-teacher teacher@test.ru "Иванова Мария"
2. Раздел «Результаты» (/admin): таблица попыток; фильтры по группе, методике,
   уровню, статусу, ФИО, датам; счётчик «Найдено строк».
3. Экспорт: «Экспорт CSV» (результаты по методикам), «Матрица SPSS»
   (строки — испытуемые, столбцы — шкалы), ссылка «Портрет» в строке таблицы.
4. «Валидатор» (/admin/validate): отчёт целостности модуля перед запуском.

## Частые проблемы
- Команда flask не найдена — не активировано окружение: .venv\Scripts\activate
- Порт занят: flask --app wsgi run --port 5050
- Чистая база для демонстрации: остановить сервер, удалить папку instance.
