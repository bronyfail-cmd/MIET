# Формат результата и «Портрета личности»

## Результат методики (методика → сборщик)
{"method_id": "coping", "title": "Стратегии совладания", "score": 21.0,
 "max_score": 30.0, "percent": 0.7, "level": "высокий",
 "interpretation": "текст вывода", "subscales":
   {"active_cope": {"score": 5.0, "max": 6.0, "percent": 0.833}},
 "answered": 30, "skipped": [], "status": "ok"}

Поля: score/max_score — балл и максимум; percent — доля (0..1); level — имя
уровня из levels методики; interpretation — текст вывода (для ipsative — описание
доминантного стиля); subscales — разбивка по субшкалам; status: "ok" или
"incomplete" (пропусков больше 20% или нет ответов).

## Портрет (сборщик → интерфейс)
{"sections": [ <результат методики>, ... ],
 "summary": {"missing": ["id..."], "invalid": [{"method_id": "...", ...}]}}
- sections — по одной на подключённую методику, без дубликатов;
- missing — методики, не приславшие результат; invalid — приславшие битый;
- веб-страница /result/<id> добавляет блок person (ФИО, группа) и выводит
  sections с баллами, уровнями и интерпретациями.

## Матрица для SPSS (/admin/export_matrix.csv)
Строки — завершённые попытки (по одной на attempt), столбцы:
attempt_id, ФИО, Группа, Завершено, далее <method_id>_<subscale> для каждой
субшкалы каждой методики (балл субшкалы). Методики без субшкал в матрицу не
входят — их общие баллы есть в /admin/export.csv. Разделитель ";", кодировка
UTF-8 BOM (открывается Excel и импортируется в SPSS).
