# Архитектура

```
Браузер ──► web.py (Flask) ──► engine.Survey ──► methods (Methodology.questions)
                │                    │
                │                    └─ grouped_answers() ─┐
                ▼                                          ▼
             SQLite  ◄── results/portrait ◄── collector.collect_from_methods ◄── Methodology.score
                                  ▲
                          validator.validate (до запуска и по /admin/validate)
```

## Движок (`engine.Survey`)
- Принимает словарь методик и порядок. Вопросы всех блоков склеиваются в один
  поток — **блоками по методикам в заданном порядке**.
- Состояние (ответы, позиция) хранится в БД; движок пересоздаётся на каждый запрос.
- Навигация: `next()`, `prev()` (границы не нарушаются), `current()`, `is_last()`.
- Ответ проверяется по вариантам вопроса; пропуск — `skip()` (значение `None`).
- Непосещённые вопросы при завершении считаются пропущенными.
- **Ошибки блоков:** блок, который не подключён, бросил исключение или вернул
  пустой список, не останавливает опрос — он попадает в `Survey.errors`,
  пользователь видит предупреждение, остальные блоки работают.

## Сборщик (`collector`)
- Каждый результат идентифицируется парой `method_id` + `team`.
- Формат результата проверяется (`check_result_format`): поля, типы, диапазоны.
- **Выбор лучшей реализации из пары** — по порядку критериев:
  1. корректность формата, 2. полнота (больше обработанных ответов), 3. скорость.
- Спектр без результата → секция `status: "missing"`; битый → `"invalid"`.
  Данные не теряются молча, счётчики лежат в `summary`.
- Дубликатов нет: на одну методику в портрете ровно одна секция.

## Методики
Данные отдельно от кода: JSON с вопросами, ключами (обратные пункты, верные
варианты), субшкалами и уровнями (низкий/средний/высокий) с текстами выводов.
Подсчёт нормируется по отвеченным вопросам; если пропущено более 20% вопросов,
статус результата `incomplete`.

## База данных
`users` (роль student/teacher) · `attempts` (статус, позиция, портрет JSON) ·
`answers` (NULL = пропуск) · `results` (плоская таблица для фильтрации по
группе, методике, уровню, статусу, датам, ФИО).

## Допущения

  `Methodology.score()` и сериализация портрета.
