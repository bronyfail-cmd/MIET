# Портрет личности — модуль тестирования студентов

Веб-приложение на Python (Flask + SQLite): личный кабинет студента, прохождение опроса
по 20 психологическим методикам, итоговый «Портрет личности», раздел преподавателя
с фильтрацией и экспортом, валидатор целостности модуля.

Учебная практика УП.01.01 / ПМ.01, колледж ЭИ МИЭТ.

## Возможности

- **Регистрация и вход** студентов с валидацией ФИО и группы.
- **Прохождение опроса**: 491 вопрос по 20 методикам, навигация вперёд/назад,
  пропуск вопросов, экран паузы между смысловыми блоками, полоса прогресса.
- **Автоматический подсчёт баллов** по ключам каждой методики с учётом
  обратных пунктов и субшкал.
- **Итоговый «Портрет личности»**: баллы, проценты, уровни (низкий/средний/высокий),
  текстовая интерпретация по каждой методике.
- **Раздел преподавателя** (`/admin`): таблица результатов всех студентов,
  фильтрация по группе/методике/уровню/статусу/ФИО/дате, экспорт CSV.
- **Экспорт результатов**: JSON и CSV для каждой попытки студента.
- **Валидатор целостности**: проверка наличия методик, формата JSON,
  корректности ключей, сумм баллов.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
flask --app wsgi init-db
flask --app wsgi validate                              # проверка модуля
flask --app wsgi create-teacher teacher@example.com "Фамилия Имя"   # доступ к /admin
flask --app wsgi run                                   # http://127.0.0.1:5000
python -m pytest                                       # 42 passed
```

## Запуск на Windows (по шагам)

1. Установите Python 3.10+ с https://www.python.org/downloads/ — на первом экране
   установщика включите галочку **Add python.exe to PATH**. Проверка: `python --version`.
2. Распакуйте проект, например в `C:\Projects\MIET`. В проводнике откройте папку,
   где лежит `wsgi.py`, в адресной строке введите `cmd` и нажмите Enter.
3. Создайте и включите виртуальное окружение (один раз):

```bash
python -m venv .venv
.venv\Scripts\activate
```

В начале строки появится `(.venv)`.
В PowerShell при ошибке про выполнение сценариев: `Set-ExecutionPolicy -Scope Process Bypass`.

4. Установите библиотеки (один раз): `pip install -r requirements.txt`
5. Проверьте тесты (по желанию): `python -m pytest` → `42 passed`.
6. Запустите сайт: `flask --app wsgi run` и откройте http://127.0.0.1:5000
   Окно терминала не закрывайте; остановка — `Ctrl + C`.
7. Учётка преподавателя (раздел «Результаты» и «Валидатор»): остановите сервер и выполните
   `flask --app wsgi create-teacher teacher@test.ru "Иванова Мария"`, затем снова запустите сайт.

**Важно:** в каждом новом окне терминала сначала выполняйте `.venv\Scripts\activate`,
иначе команды `flask` и `pytest` не найдутся.

Если порт 5000 занят: `flask --app wsgi run --port 5050`.
Чистая база: остановите сервер и удалите папку `instance`.

## Структура

| Путь | Назначение |
| --- | --- |
| `app/engine.py` | Движок опроса: единый поток вопросов, навигация, приём ответов и пропусков, группировка по методикам |
| `app/collector.py` | Сборщик результатов: проверка формата, выбор лучшей реализации из пары, сборка «Портрета личности» |
| `app/methods/base.py` | Контракт методики и подсчёт баллов по ключам |
| `app/methods/data/*.json` | **20 боевых методик** (вопросы, ключи, уровни, тексты интерпретации) |
| `app/validator.py` | Валидатор: наличие методик, формат, целостность, суммы баллов, ключи |
| `app/web.py`, `app/templates/` | Сайт: регистрация/вход, кабинет, опрос, результаты, `/admin` |
| `app/db.py` | Схема SQLite, CLI-команды |
| `tests/` | Автотесты (pytest, 42 теста) |
| `docs/` | Архитектура, контракты данных, тест-план |

## Как добавить методику

1. Создайте JSON-файл в `app/methods/data/` по формату из `docs/contracts.md`.
   Поддерживаются два формата `options` для choice-вопросов:
   - простой: `["вариант 1", "вариант 2", ...]`
   - объекты: `[{"value": 0, "label": "верно"}, {"value": 1, "label": "неверно"}]`
2. Для scale-методик: в `scale.labels` задаются баллы ключа — интерфейс показывает
   позиции 1..N, а баллы используются при подсчёте.
3. Запустите валидацию и тесты:

```bash
flask --app wsgi validate
python -m pytest
```

Код править не нужно — методика подхватится автоматически.

## Деплой на хостинг

```bash
export SECRET_KEY="длинная-случайная-строка"
gunicorn -w 2 -b 0.0.0.0:8000 wsgi:app
```

База — файл `instance/app.sqlite3` (делайте его резервные копии). На
PythonAnywhere/Render/любом VPS достаточно указать `wsgi:app` как точку входа
и задать `SECRET_KEY`. Для HTTPS ставьте перед gunicorn nginx/прокси хостинга.

## Безопасность

- Пароли хранятся хэшами (werkzeug).
- CSRF-токены на всех POST-запросах.
- Параметризованные SQL-запросы, фильтрация ввода устойчива к SQL-инъекциям.
- Студент видит только свои результаты; `/admin` — только роль `teacher`.
- Защита от open redirect при входе.
- Валидация ФИО и группы при регистрации (отказ в мусорных данных).

## Тестирование

```bash
python -m pytest -q
```

Покрытие:
- загрузчик методик (битые JSON, отсутствующие ключи),
- движок опроса (навигация, пропуски, группировка, изоляция ошибок блоков),
- сборщик (формат, выбор лучшей реализации, исключения в блоках),
- валидатор (присутствие, целостность, ключи, уровни),
- веб-слой (регистрация, опрос, результаты, админка, фильтры, экспорт).
