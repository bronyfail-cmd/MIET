# Портрет личности — модуль тестирования студентов

Веб-приложение на Python (Flask + SQLite): личный кабинет, прохождение опроса
по методикам, итоговый «Портрет личности», раздел преподавателя с фильтрацией
и экспортом, валидатор целостности модуля.

Учебная практика УП.01.01 / ПМ.01, колледж ЭИ МИЭТ.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
flask --app wsgi init-db
flask --app wsgi validate                              # проверка модуля
flask --app wsgi create-teacher teacher@example.com "Фамилия Имя"   # доступ к /admin
flask --app wsgi run                                   # http://127.0.0.1:5000
pytest                                                 # тесты
```

## Структура

| Путь | Назначение |
|---|---|
| `app/engine.py` | Движок опроса: единый поток вопросов, навигация, приём ответов и пропусков, группировка по методикам |
| `app/collector.py` | Сборщик результатов: проверка формата, выбор лучшей реализации из пары, сборка «Портрета личности» |
| `app/methods/base.py` | Контракт методики и подсчёт баллов по ключам |
| `app/methods/data/*.json` | Методики (вопросы, ключи, уровни, тексты интерпретации) |
| `app/validator.py` | Валидатор: наличие методик, формат, целостность, суммы баллов, ключи |
| `app/web.py`, `app/templates/` | Сайт: регистрация/вход, кабинет, опрос, результаты, `/admin` |
| `app/db.py` | Схема SQLite, CLI-команды |
| `tests/` | Автотесты (pytest) |
| `docs/` | Архитектура, контракты данных, тест-план |

## Как добавить методику

Положите JSON в `app/methods/data/` (формат — `docs/contracts.md`), затем
`flask --app wsgi validate` и `pytest`. Код менять не нужно.
В репозитории лежат три **демо-методики с вопросами-заглушками** — замените их
материалами от заказчиков (флаг `"demo": true` убрать).

## Деплой на хостинг

```bash
export SECRET_KEY="длинная-случайная-строка"
gunicorn -w 2 -b 0.0.0.0:8000 wsgi:app
```

База — файл `instance/app.sqlite3` (делайте его резервные копии). На
PythonAnywhere/Render/любом VPS достаточно указать `wsgi:app` как точку входа
и задать `SECRET_KEY`. Для HTTPS ставьте перед gunicorn nginx/прокси хостинга.

## Безопасность

Пароли хранятся хэшами (werkzeug), CSRF-токены на всех POST, параметризованные
SQL-запросы, студент видит только свои результаты, `/admin` — только роль
преподавателя, защита от open redirect при входе.
